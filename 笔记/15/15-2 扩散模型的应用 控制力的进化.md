## 第二部分：控制力的进化

底座能力成熟后，研究重心转向"按意图生成"。

控制力依托模型结构逐步加强：

- **特征层** ➜ **ControlNet**：在 U-Net 特征层注入结构控制
- **条件通道层** ➜ **IP-Adapter**：解耦图像/文本的独立条件通道
- **注意力图层** ➜ **Prompt-to-Prompt**：推理时直接编辑 attention map

从线条式结构控制 → 语义画风级参考 → 像素级推理期编辑，控制精度持续提升。

## Control Net
### 核心结构
![[15-2-fig-1.png|489]]
- **锁定骨干**：原始 SD block $F(x; \Theta)$ 完全冻结，保留预训练生成能力

- **可训练副本**：克隆分支 $F(\cdot; \Theta_c)$ 学习如何用条件修改特征

- **Zero Convolution $\mathcal{Z}$**：$1 \times 1$ 卷积初始化为**全零**

**残差思想**

训练初始 $\mathcal{Z}(\cdot) = 0 \Rightarrow y_c = y$，ControlNet 对预训练模型零影响。

先"保持沉默"，学会之后再"发声"。

### **Zero Convolution $\mathcal{Z}$
![[15-2-fig-2.png]]

- **(a) 有 zero conv**：在各种 prompt 下**稳定生成**。
- **(b) 无 zero conv**：随机初始化直接污染特征 → 生成**崩塌**。
- **(c) 从头训练**：丢失预训练能力 → **完全失败**。
### 具体结构
![[15-2-fig-3.png|390]]

- 复制 U-Net 的 12 个 encoder blocks 和 1 个 middle block 作为可训练分支
- 条件 $c_f$（Canny/Depth/Pose）通过 zero conv 从顶部注入
- 分支输出走 skip connections 加入到 Decoder 和 middle block
- 条件信息可作用于 Decoder 所有空间尺度
- 原始 SD blocks 全部冻结，节省显存

**ControlNet 通过向原 U-Net 的多尺度 skip features 和 middle feature 注入条件残差，实现对整个重建过程的控制**

### 复习：LDM 的原始 Cross-Attention
![[15-2-fig-4.png]]
**原始 Cross-Attention**

$$ \text{Attn}_{\text{text}} = \text{Softmax}\left( \frac{QK^\top}{\sqrt{d}} \right) V $$

- $Q$：来自 U-Net 当前 latent feature（图像侧）
- $K, V$：来自文本特征 $\tau_\theta(\text{text})$（语言侧）
- 含义：图像特征向文本 token 发起"查询"，决定在哪里生成什么

原始 SD 里，U-Net 拿自己的 feature 当 query，去和文本 token 做 cross-attention。

## IP-Adapter:

**IP-Adapter 的关键问题：图像 prompt 要走哪条路？**
![[15-2-fig-5.png]]
##### 冻结模块

Image encoder、text encoder、原始 U-Net cross-attention。
##### 可训练模块

Linear projection、LayerNorm、新增 image cross-attention（$W'_k$, $W'_v$）。
##### 核心设计

text 管语义，image 管身份/风格，两条路径独立后再汇合。

#### IP-Adapter：解耦 Cross-Attention 公式

**新增图像 Cross-Attention**

$$ Z' = \text{Attention}(Q, K', V') = \text{Softmax}\left( \frac{Q K'^\top}{\sqrt{d}} \right) V' $$

$Q = Z W_q$（共享 query），$K' = c_i W'_k$，$V' = c_i W'_v$，$c_i$ 为图像特征，$W'_k, W'_v$ 为新增可训练投影。

**解耦输出**

$$ Z_{\text{new}} = \underbrace{ \text{Softmax}\left( \frac{QK^\top}{\sqrt{d}} \right) V }_{\text{文本 attention}} + \underbrace{ \text{Softmax}\left( \frac{QK'^\top}{\sqrt{d}} \right) V' }_{\text{图像 attention}} $$

文本分支处理语义，图像分支处理参考内容/风格，两路独立后相加。

**参数减少**

每个 cross-attention 层只新增 $W'_k$ 和 $W'_v$，query $Q$ 复用文本分支——轻量且高效。 
![[15-2-fig-6.png]]
- 参考图提供 base identity/风格，文本继续修改局部属性（如"wearing a top hat"、"blue hair"）。
- 两条独立的 attention 路径各自作用到生成结果上，互不干扰。
![[15-2-fig-7.png]]
- **IP-Adapter 与 ControlNet 条件**（Canny/Pose/Depth）**直接兼容**，无需额外 fine-tuning。
- 图像 prompt 管风格，ControlNet 条件管布局——控制能力在叠加。

## Prompt-to-Prompt

![[15-2-fig-8.png]]
- **Cross-attention map 充当空间布局控制器**：每个 text token 的 attention map 决定该概念出现的位置。
- 扩散**早期阶段**的 cross-attention 基本决定了物体的位置，**后期步骤**只负责细节渲染。

![[15-2-fig-9.png]]
##### 核心创新 1

通过 cross-attention map 灵活编辑文本-空间布局。
##### 核心创新 2

推理时注入源 attention map — 无需新模型，直接"劫持"已有的 attention 流。

这是 inference-time control，不是 retraining。
##### 核心创新 3

三种编辑操作：**Word Swap**、**Adding Phrase**、**Re-weighting**。

### 局部改动，整体结构不动
![[15-2-fig-10.png]]
- 示例："a cat riding a **bicycle**" → "a cat riding a **motorcycle**"
- 早期步骤（$t < \tau$）注入源 attention → **保留构图**；后期步骤用目标 attention → **适配新词**。
- $\tau$ 决定"改多少语义、保留多少结构"。

## 总结
#### 控制力在向更细粒度持续推进

- **ControlNet** — 控制空间结构（feature-level）
- **IP-Adapter** — 控制参考图语义/身份（condition-level）
- **Prompt-to-Prompt** — 控制推理期 prompt 微调 attention（inference-time）

### 控制力的推进：三个层次

**条件层（训练时注入）**

- **LDM Cross-Attention**：文本/图像经编码器 $\tau_\theta$ 映射为 $K, V$，注入 U-Net 每层

**特征层（结构复制注入）**

- **ControlNet**：冻结主干，Zero Conv 将结构条件叠加到各尺度特征

**推理层（不改权重）**

- **Prompt-to-Prompt**：替换/注入/重加权 attention map，零参数改变构图

### 图像提示与 Transformer 时代的条件注入

**IP-Adapter：解耦双路 Cross-Attention**

**DiT adaLN-Zero: Scale / Shift 条件**

> 图像特征与文本特征走**独立** Cross-Attention，**互不干扰**，可自由组合：图像编码器可训练，主干冻结
