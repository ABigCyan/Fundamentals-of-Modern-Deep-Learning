### 命名约定

- **文件名**: `{课次}-{sub序号} {标题}.md`
  - 例: `13-1 扩散生成模型 DDPM.md`
- **sub-section 编号**(`-1` / `-2` / `-3`)= **主题切片**,不严格对应视频分 P
- **章节内部编号**(如流匹配用 `14-` 编号)沿用上一章的主题槽数,与课程课次不对齐时以 [课程索引.md](./课程索引.md) 为准

### 笔记格式

- LaTeX 数学公式
- `> [!note]` / `> [!warning]` Obsidian callout
- `![[图/xxx.png]]` 图片嵌入
- 代码块使用 ``` ` `` 标注语言
