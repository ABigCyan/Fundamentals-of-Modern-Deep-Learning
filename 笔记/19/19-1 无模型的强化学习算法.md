## 模仿学习 vs 强化学习
![[19-1-fig-1.png]]

### 一、RL 通过 advantage 信号提供**动作级**的信用分配。

#### 形式化

**行为克隆（IL，Behavior Cloning）**：

$$\nabla_\theta J_{BC} = \mathbb{E}_{(s,a) \sim \mathcal{D}_{expert}} \left[ \nabla_\theta \log \pi_\theta(a|s) \right] = \mathbb{E}\!\left[ \frac{1}{\pi_\theta(a|s)} \nabla_\theta \pi_\theta(a|s) \right]$$

**策略梯度（RL，Policy Gradient）**：

$$\nabla_\theta J_{RL} = \mathbb{E}_{(s,a) \sim \pi_\theta} \left[ A^\pi(s, a)\, \nabla_\theta \log \pi_\theta(a|s) \right]$$

#### 关键区别

- **BC**：基于似然的加权（likelihood-based weighting）
- **RL**：基于 advantage 的加权（advantage-based weighting）

#### 推论

- **BC** 只会**提高专家动作的概率**
- **RL** 可以通过 $A^\pi$ **强化或抑制**动作

### 二、RL 通过在**自身状态分布**下学习来缓解误差累积。

#### 形式化

$$J(\pi_{BC}) \leq J(\pi^*) + \sum_{t=1}^{T} O(t\epsilon) = J(\pi^*) + O(T^2 \epsilon)$$

$$J(\pi_{RL}) \approx O(T\epsilon)$$

#### 关键区别

- **BC**：误差**二次增长**（quadratic error growth）
- **RL**：误差**线性增长**（linear error growth）

#### 机制
 
- **BC** 在 $s \sim \mathcal{D}_{expert}$（开环）上训练，部署时使用 $s \sim \pi_\theta$ → **分布偏移**
- **RL** 在线策略训练 → 包含**恢复状态**（recovery states）

> [!note]
> BC 策略的表现，和最优策略相比，最坏情况下可能随着时间步 $T$ 的增加，以 $T^2\epsilon$ 的速度变差。
> RL 的误差大约只随 $T$ 线性增长。
>

### 三、RL 可以在优化过程中**显式惩罚最坏情况**。

#### 形式化

**期望目标**（Expectation objective）：

$$\max_\theta \mathbb{E}[R]$$

**尾风险惩罚目标**（Tail-risk penalized objective）：

$$\max_\theta \mathbb{E}[R] - \lambda\, \mathbb{E}\!\big[(\tau - R)_+\big]$$

#### 关键区别

- **IL**：模仿专家动作，**无法直接重加权**稀有的坏结果
- **RL**：可以对**低回报（尾风险）**事件施加更强惩罚

#### 机制 

- **RL 的目标可修改**（modifiable）——支持**奖励/惩罚塑形**（reward / penalty shaping）
- 提高对不安全动作的惩罚权重 → 策略更**安全**

### 四、RL 通过**环境反馈**获得更丰富的监督信号。

#### 监督来源（Supervision source）

- **模仿学习（IL）**：$(s, a^*)$
- **强化学习（RL）**：$(s, a, r, s')$

#### 关键区别

- **IL** 只观察**专家采取了什么动作**
- **RL** 还能**额外观察**每个动作的**结果**

#### 机制

- **奖励**提供**任务级**（task-level）的显式评估
- **下一状态转移**揭示动作的**后果**（consequence of an action）

> [!note]
> ### 五、从数据和实践来看
> 
> RL 需要一个环境，并不需要像 IL 一样去学习专家的 action。
> 
> RL 书籍里面，reward 可以理解为隐形地包含了“这个 action 做得好不好”的信息，不需要专家直接告诉你应该采取什么 action。只需要让 agent 见到足够多的 state 和 $s'$，通过与环境交互获得 reward，就可以逐渐学到一个差不多的 policy。
> 
> 有一些场景下，action 数据很难采集。相对来说，RL 的数据采集难度可能更小一些，而且某些情况下对数据量的需求也更少，就能够学到差不多的 policy。
>

# 无模型 RL 方法概览

**问题设定**：在环境反馈下的序贯决策

$$\max_\pi \mathbb{E}_{\tau \sim \pi} \left[ \sum_{t=0}^{T} \gamma^t r_t \right]$$

- **核心挑战**：动作不仅影响**即时奖励**，还会影响**未来状态**
- **无模型 vs. 有模型**
  - **有模型 RL**：学习或使用**转移动力学** $p(s'|s, a)$
  - **无模型 RL**：直接从**采样交互**中学习**策略 / 价值**

- **策略（Actor）**：$\pi_\theta(a|s)$ 将状态 $s$ 映射到动作 $a$
- **环境**：给定 $a_t$，返回奖励 $r_t$ 和下一状态 $s_{t+1}$

## 交互与学习（Interaction and Learning）

- **Rollout 轨迹**：$\tau = (s_0, a_0, r_0, \ldots, s_T)$
- **计算回报**：$G_t = \sum_{k=t}^{T} \gamma^{k-t} r_k$
- **更新策略**以提高**高回报**动作的概率

## 仅策略方法（Policy-only Methods）的局限

- 学习信号 = 蒙特卡洛回报 $G_t$
- 由于**奖励延迟且有噪声**而导致**高方差**
## 引入 Critic!

- Critic 学习一个**价值函数**：**状态价值** $V(s)$ 或**动作价值** $Q(s, a)$
- $V(s)$ 估计**从状态 $s$ 出发**的期望未来奖励；$Q(s, a)$ 估计**在状态 $s$ 采取动作 $a$ 之后**的期望未来奖励
- 这些价值估计提供了一个**更即时、噪声更小**的学习信号，引导 Actor **更稳定地**更新策略

# 深度 Q 网络（DQN）

- **动机（Motivation）**：使用神经网络 $Q_\theta(s, a)$ 替代 Q-learning 表格，以在**大或连续状态空间**中近似动作价值
- **训练目标（Training target）**：

$$y_t = r_t + \gamma \max_{a'} Q_\theta(s_{t+1}, a')$$

最小化**时序差分误差**（temporal-difference error）：

$$\mathcal{L}(\theta) = \mathbb{E}_{(s,a,r,s') \sim \mathcal{D}} \left[ \big(y_t - Q_\theta(s, a)\big)^2 \right]$$

- **策略（Policy）**：给定状态 $s$，按如下方式选择动作

$$a^\star = \arg\max_a Q_\theta(s, a)$$

  - **训练**时通常用 **$\epsilon$-贪心**进行探索
  - **评估**时通常用**贪心动作选择**

# DQN：经验回放（Experience Replay）

- **核心思想**：将转移存放在**固定容量**的回放缓冲池 $\mathcal{D}$ 中，训练时从中**随机采样**小批量
- **转移格式**：

$$(s_t, a_t, r_t, s_{t+1}, d_t), \quad d_t \in \{0, 1\}$$

其中 $d_t = 1$ 表示回合终止。

- **它为什么有效**
  - **打破时间相关性（Break temporal correlation）**：从 $\mathcal{D}$ 中随机采样小批量，使得**连续数据去相关**
  - **提高样本效率（Improve sample efficiency）**：存储的转移可以被**多次复用**，减少昂贵的环境交互
  - **平滑分布偏移（Smooth distribution shift）**：$\mathcal{D}$ 中**新旧数据混合**，可平滑分布并减少震荡

# DQN：目标网络（Target Network）

- **核心思想**：维护**两个 Q 网络**：$Q_\theta$（在线网络，每步更新）和 $Q_{\theta^-}$（目标网络，缓慢更新）
- **TD 目标构造**：

$$y = r + \gamma (1 - d) \max_{a'} Q_{\theta^-}(s', a')$$

使用 $Q_{\theta^-}$ 可以**避免追逐快速移动的目标**。

- **如何更新 $Q_{\theta^-}$**
  - **硬更新（Hard update）**：每隔 $C$ 步将在线网络权重**直接复制**给目标网络：$\theta^- \leftarrow \theta$
  - **软更新（Soft update）**：$\theta^- \leftarrow \tau \theta + (1 - \tau) \theta^-$，其中 $\tau \ll 1$
- **为什么有效**：使**短期窗口内标签相对稳定**，从而**降低发散风险**

# 深度确定性策略梯度（DDPG）

- **动机**：DQN 需要求解 $a^\star = \arg\max_a Q(s, a)$，在**连续动作空间**中**不可行**（如自动驾驶中的转向角、油门、刹车）
- **训练目标**：引入**确定性 Actor** 来替代 arg max：
  - **Actor**：$a = \mu_\phi(s)$
  - **Critic**：$Q_\theta(s, a)$

Actor 与 Critic **迭代更新**：

- **Critic 目标**：用**目标 Actor** 替代 DQN 中的 $\max_{a'}$：

$$y_t = r_t + \gamma (1 - d_t)\, Q_\theta\big(s_{t+1},\ \mu_\phi(s_{t+1})\big)$$

- **Actor 更新**：通过**确定性策略梯度**最大化 Critic 价值：

$$\max_\phi \mathbb{E}_{s \sim \mathcal{D}} \left[ Q_\theta\big(s,\ \mu_\phi(s)\big) \right]$$

- **策略**：$a^\star = \mu_\phi(s)$

# DDPG：探索与目标网络

- **带探索的确定性策略**
  - Actor 输出**确定性动作**：$a = \mu_\phi(s)$
  - 通过**加入外部噪声**实现探索：$a_t = \mu_\phi(s_t) + \epsilon_t$
- **带软更新的目标网络**
  - 维护**独立的目标 Actor** $\mu_{\phi^-}$ 与 **目标 Critic** $Q_{\theta^-}$
  - TD 目标：$y = r + \gamma(1 - d)\, Q_{\theta^-}\big(s',\ \mu_{\phi^-}(s')\big)$
  - **软更新**保持目标稳定：

$$\theta^- \leftarrow \tau \theta + (1 - \tau)\, \theta^-, \qquad \phi^- \leftarrow \tau \phi + (1 - \tau)\, \phi^-$$

# 软 Actor-Critic（SAC）

- **动机**：DDPG 因采用**外部噪声**进行探索而**不稳定**。SAC 的改进方法：
  - 使用**随机策略**：$a \sim \pi_\phi(a|s)$
  - 加入**熵正则化**以鼓励探索
- **训练目标**：**最大熵**目标：

$$\max \mathbb{E}\!\left[\sum_t r_t + \alpha\, \mathcal{H}\big(\pi(\cdot|s_t)\big)\right], \quad \mathcal{H}(\pi) = -\mathbb{E}_{a \sim \pi}\big[\log \pi(a|s)\big]$$

- **Critic 目标**：将 max 替换为**采样动作**，并**减去熵项**：

$$y_t = r_t + \gamma(1 - d_t) \left( \min_{i=1,2} Q_{\theta_i^-}(s_{t+1}, a_{t+1}) - \alpha \log \pi_\phi(a_{t+1}|s_{t+1}) \right)$$

其中 $a_{t+1} \sim \pi_\phi(\cdot|s_{t+1})$。

- **Actor 目标**：

$$\max_\phi \mathbb{E}_{a \sim \pi_\phi} \left[ Q(s, a) - \alpha \log \pi_\phi(a|s) \right]$$

# SAC：温度系数与重参数化策略

- **温度系数（Temperature coefficient）**：$\alpha$ 控制**探索与利用**的权衡：
  - $\alpha$ 较大：**更高熵**，探索**更强**
  - $\alpha$ 较小：**更低熵**，策略更**确定性**

实践中，SAC 通常**自动学习 $\alpha$**：引入**目标熵** $\mathcal{H}_{\text{target}}$，并最小化**温度损失**：

$$\mathcal{L}(\alpha) = \mathbb{E}\!\left[-\alpha \log \pi_\phi(a|s) + \mathcal{H}_{\text{target}}\right]$$

自适应 $\alpha$ 以匹配目标熵：**低熵 ↑ $\alpha$**，**高熵 ↓ $\alpha$**。

- **重参数化策略（Reparameterized policy）**：实现**可微且有界**的动作采样：

$$a = \tanh(u), \quad u = \mu_\phi(s) + \sigma_\phi(s) \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

**评估**时通常使用**确定性均值动作**：$a_{\text{test}} = \tanh(\mu_\phi(s))$

# 从 SAC 到策略梯度方法

- **已有方法（DQN, DDPG, SAC）**：
  - 使用**回放缓冲池**的离线策略学习
  - Critic 学习 $Q(s, a)$
  - Actor 由价值函数指导
- **局限**：
  - 训练**复杂**（目标网络、回放缓冲池）
  - 对**超参数敏感**
- **替代方向**：
  - 通过**策略梯度直接优化策略**
  - 通常是**在线策略**
- **关键问题**：
  - 如何让**策略梯度既稳定又高效**？ 

# 优势 Actor-Critic（A2C）

- **从 REINFORCE 出发**：

$$\nabla_\theta J(\theta) = \mathbb{E}_{(s,a) \sim \pi_\theta} \left[ \nabla_\theta \log \pi_\theta(a|s)\, G_t \right], \quad G_t = \sum_{l=0}^{\infty} \gamma^l r_{t+l}$$

- **方差缩减**：减去一个**不依赖动作**的基线 $b(s)$：

$$\nabla_\theta J(\theta) = \mathbb{E}\left[ \nabla_\theta \log \pi_\theta(a|s)\, \big(G_t - b(s)\big) \right]$$

- **选取价值函数作为基线**：

$$A_t \approx G_t - V_\phi(s_t)$$

- **A2C 的 Actor 更新**：

$$\nabla_\theta J(\theta) = \mathbb{E}\left[ \nabla_\theta \log \pi_\theta(a|s)\, A_t \right]$$

# A2C：优势估计

- **Actor-Critic 角色**：
  - **Actor**：$\pi_\theta(a|s)$ 输出动作分布
  - **Critic**：$V_\phi(s)$ 为**低方差更新**提供**基线**
- **优势的定义与估计**：

$$A^\pi(s_t, a_t) = Q^\pi(s_t, a_t) - V^\pi(s_t) \;\Rightarrow\; A_t \approx r_t + \gamma V_\phi(s_{t+1}) - V_\phi(s_t)$$

- **对 $\nabla_\theta \log \pi_\theta(a|s)\, A(s, a)$ 的解读**：
  - 若 $A(s, a) > 0$：**提高**动作 $a$ 的概率
  - 若 $A(s, a) < 0$：**降低**动作 $a$ 的概率
  - 策略通过**强化优于状态平均水平**的动作来学习 

# 广义优势估计（GAE）

- **动机**：优势估计存在**偏差-方差权衡**：
  - **蒙特卡洛**：低偏差、**高方差**
  - **TD**：**低方差**、高偏差

**GAE** 通过对**多步 TD 残差**做**指数加权平均**来兼顾两者。

- **TD 残差**：

$$\delta_t = r_t + \gamma V_\phi(s_{t+1}) - V_\phi(s_t)$$

- **GAE 估计量**：

$$A_t^{\text{GAE}(\lambda)} = \sum_{l=0}^{\infty} (\gamma \lambda)^l\, \delta_{t+l}$$

- **解读**：
  - $\lambda = 0$：接近**单步 TD**（**更低方差**）
  - $\lambda = 1$：接近**蒙特卡洛回报**（**更低偏差**）

# 信赖域策略优化（TRPO）

- **动机**：A2C 与 GAE 改进了**估计好的策略梯度**的方法。已知梯度之后，**下一步问题**就是**如何稳定地更新策略**。

若策略**更新过于激进**，可能导致：
  - **分布不匹配（Distribution mismatch）**：当策略变化过大时，**旧的 rollout** 不再能代表**新策略**
  - **性能不稳定（Unstable performance）**：大幅更新会**剧烈改变动作和状态分布**，从而引发**性能突然崩溃**

- **核心思想**：把每次更新**限制在一个信赖域**（小步策略变化）内，这样既能**使用策略梯度**，又能**保证稳定提升**

# TRPO：约束优化及其性质

通过 **KL 散度**限制策略变化：

- **目标**：

$$\max_\theta \mathbb{E}\left[ \frac{\pi_\theta(a|s)}{\pi_{\theta_{\text{old}}}(a|s)}\, A(s, a) \right] \quad \text{subject to} \quad \mathbb{E}\!\left[ D_{\text{KL}}\!\left(\pi_{\theta_{\text{old}}} \,\|\, \pi_\theta\right) \right] \leq \delta$$

- **解法**：需要**二阶优化**
  - **局部近似**：对**代理目标**做**线性化**，对**KL 约束**在**旧策略附近**做**二次近似**
  - **自然梯度步**：用**共轭梯度**求解**信赖域更新方向**，**不显式求逆** Fisher / Hessian 矩阵
  - **安全的步长**：采用**回溯线搜索（backtracking line search）**，在**满足 KL 约束**的前提下保证**策略提升**

# 近端策略优化（PPO）

- **动机**：TRPO 有效但**实现复杂**；PPO 通过**一阶优化**保持**稳定更新**
- **核心思想**：通过对**策略比率**做**裁剪**（clipping）来近似**信赖域约束**
- **重要性比率**：

$$r_t(\theta) = \frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_{\text{old}}}(a_t|s_t)}$$

- **裁剪目标**：

$$L^{\text{CLIP}}(\theta) = \mathbb{E}\left[ \min\!\big(r_t A_t,\ \text{clip}(r_t,\ 1 - \epsilon,\ 1 + \epsilon)\, A_t\big) \right]$$

- **效果**：在**保留改进方向**的同时**限制策略更新过大**
