# State Space 建模

## PETS：Probabilistic Ensembles with Trajectory Sampling

**核心贡献**：用**概率集成模型**显式区分两类不确定性，结合 **CEM-MPC Planning**。

动态模型的误差可以拆成两部分：

- **Aleatoric（偶然不确定性）**：环境本身的随机性 ⇒ 概率模型输出分布
- **Epistemic（认知不确定性）**：数据不足造成 ⇒ **Probabilistic Ensemble**

### Probabilistic Ensemble (PE)

每个集成成员输出**高斯分布**而非点估计：

$$\hat{p}_{\phi_b}(s' \mid s, a) = \mathcal{N}\!\big(\mu_{\phi_b}(s, a),\ \Sigma_{\phi_b}(s, a)\big)$$

- 训练 $B$ 个网络（典型 $B = 5$），各自在 **bootstrap 子集**上独立训练
- 损失：**负对数似然**（NLL）

$$\mathcal{L}(\phi_b) = \sum_{(s, a, s')} \frac{1}{2}(s' - \mu_{\phi_b})^\top \Sigma_{\phi_b}^{-1} (s' - \mu_{\phi_b}) + \frac{1}{2} \log \det \Sigma_{\phi_b}$$

- **概率输出 → 捕获 aleatoric**
- **集成 → 捕获 epistemic**

> [!note]
> 
> 这块主要来自 Bayesian Deep Learning，核心讨论模型预测中的不确定性。
> 
> 不确定性一般分成两种：
> 
> 1. **Aleatoric Uncertainty**  
>     问题本身就有不确定性，比如数据噪声、图像模糊，这种不确定性即使数据再多也不一定能消除。
>     
>     常见做法是让网络除了预测结果，还额外预测一个 variance：
>     
>     $(μ,σ2)=fθ(x)(\mu,\sigma^2)=f_\theta(x)$
>     
>     实际一般预测 $\log \sigma^2$，然后把这个方差一起放进 loss 里训练。  
>     代表工作：Kendall & Gal, 2017。
>     
> 2. **Epistemic Uncertainty**  
>     问题本身可能是确定的，但是模型因为训练数据不够、没有见过类似样本，所以不确定。
>     
>     常见方法是 **ensemble**：多个模型分别预测，看结果之间差异有多大。
>     
>     在神经网络里一个很方便的方法是 **MC Dropout**：推理时仍然打开 dropout，多次 forward，相当于从不同子网络里 sample：
>     
>     $y^1,y^2,…,y^N\hat y_1,\hat y_2,\dots,\hat y_N$
>     
>     最后把均值作为预测，方差作为模型的不确定性。  
>     代表工作：Gal & Ghahramani, 2016。
>     
> 

### 为什么需要 Ensemble 才能捕获 epistemic？

单个概率模型训完只得到**一组参数** $\phi^\star$，在任何 $(s, a)$ 输出固定的 $(\mu, \Sigma)$。

- **有数据区**：$\Sigma$ 被训练去**拟合环境噪声** ✓
- **无数据区**：损失函数无梯度信号，**模型无法学到输出大 $\Sigma$** ✗

真正的 epistemic 来自**参数后验** $p(\phi \mid \mathcal{D})$：

$$p(s' \mid s, a, \mathcal{D}) = \int p_\phi(s' \mid s, a)\, p(\phi \mid \mathcal{D})\, \mathrm{d}\phi \approx \frac{1}{B} \sum_b p_{\phi_b}(s' \mid s, a)$$

用 $B$ 个独立训练的 $\phi_b$ **近似后验采样**，来**间接地**表示 epistemic。

### PETS 规划：CEM + Trajectory Sampling

在当前 $s_t$ 用 **CEM** 搜索动作序列 $a_{t:t+H-1}$，评估一条序列时：

- **TS1**：每一步随机选一个集成成员采样 $s'$
- **TS∞**（**推荐**）：同一条"粒子"**全程用同一个成员**，采 $P$ 条粒子取均值

**目标函数（回报均值）**：

$$R(a_{t:t+H-1}) = \frac{1}{P} \sum_{p=1}^{P} \sum_{k=0}^{H-1} \gamma^k\, r(s_{t+k}^{(p)}, a_{t+k})$$

> TS∞ 避免在时间上混合不同模型产生"**幻觉轨迹**"。

### PETS 算法流程

- 初始化 ensemble $\{\phi_b\}$，buffer $\mathcal{D}$
- **repeat**:
  - **# 1. CEM-MPC：与真实环境交互一个 episode**
  - **for** $t = 0 \ldots T - 1$:
    - 用 CEM 搜索 $a_t^\star$（内部用 **PE + TS∞ rollout，$H = 25$**）
    - 执行 $a_t^\star$，观测 $r_t, s_{t+1}$
    - $\mathcal{D} \leftarrow \mathcal{D} \cup \{(s_t, a_t^\star, r_t, s_{t+1})\}$
  - **# 2. 模型更新**
  - **for** $b = 1 \ldots B$:
    - 从 $\mathcal{D}$ 采样 **bootstrap 子集**，用 **NLL** 重新训练 $\phi_b$

### PETS 的优缺点

#### 优点

- **样本效率极高**：MuJoCo 上 $\sim 10^5$ 步 $\approx$ SAC $10^6$ 步
- **无策略网络**，换奖励即可复用模型
- **不确定性感知**的规划对 **model exploitation 鲁棒**

#### 缺点

- 每步 CEM 推理开销大 ⇒ 难以**实时控制**
- 集成训练成本 **$B$ 倍**
- 只适合**低 / 中维状态**，**像素输入**需要 **latent 模型**（下一章）

## MBPO：Model-Based Policy Optimization

**核心思想**

不要从初始状态长 rollout——而是从**真实 buffer 中的状态出发**，用模型 rollout **很短**的 $k$ 步，再把**虚拟数据和真实数据**一起喂给 **SAC**。

- 属于 **Background Planning 范式**
- Dyna 在深度连续控制下的**现代版本**
- 动态模型仍用 **PE**（延续 PETS），策略用 **SAC**

### 为什么要用短 rollout？

论文给出策略改进的**下界**：

$$\eta(\pi) \geq \hat{\eta}(\pi) - C(k)$$

其中 $C(k) \approx C_1 \gamma^k \epsilon_\pi + C_2 k \epsilon_m$

- $\eta / \hat{\eta}$：**真实 / 模型下**的回报
- $\epsilon_m$：**模型误差** &emsp; $\epsilon_\pi$：**策略漂移** &emsp; $k$：rollout 长度

**关键结论**：**存在最优 $k^\star$**

- $k$ 太小 ⇒ 信息利用不足
- $k$ 太大 ⇒ 误差复合爆炸

**实践**：$k$ 随训练进行**从 1 线性增加到 15**

### MBPO：Branched Rollout

- **for each epoch**:
  - **# 1. 与真实环境交互 $E$ 步**
  - 收集数据存入 $\mathcal{D}_{\text{env}}$
  - **# 2. 训练模型**
  - 用 $\mathcal{D}_{\text{env}}$ 重新训练 **PE ensemble**
  - **# 3. Branched rollout**
  - **for** $m = 1 \ldots M$:
    - 从 $\mathcal{D}_{\text{env}}$ **均匀采样状态** $s$
    - **for** $i = 1 \ldots k$:
      - $a \sim \pi(\cdot | s); \quad s', r \sim \text{Model}(s, a)$
      - $\mathcal{D}_{\text{model}} \leftarrow \mathcal{D}_{\text{model}} \cup \{(s, a, r, s')\}; \quad s \leftarrow s'$
  - **# 4. SAC 更新**
  - 在 $\mathcal{D}_{\text{env}} \cup \mathcal{D}_{\text{model}}$ 上做 $G$ 次 SAC 更新

**典型**：$E = 1000,\quad M = 400,\quad k: 1 \to 15,\quad G = 20 \sim 40$

### MBPO 为什么有效

- **rollout 起点在真实 buffer**
  状态分布 $\rho_{\text{env}}$ 接近策略当前访问分布 ⇒ **distribution shift 小**
- **$k$ 很短**
  模型误差**不会在时间维度上爆炸** ⇒ **compounding errors 可控**
- **等价于用模型做"局部 data augmentation"**
  真实样本 ≈ **锚点**，虚拟样本 ≈ 锚点附近的**扰动**

### MBPO 小结

- **MBPO = Dyna + PE + SAC + 短 branched rollout**
- MuJoCo 上 $\sim 10^5$ 步达到 SAC $3 \times 10^5 \sim 10^6$ 步水平
- **渐近性能持平或超过 MFRL**

|  | **Dyna-Q** | **PETS** | **MBPO** |
|---|---|---|---|
| Rollout 起点 | 任意历史 $(s, a)$ | 当前状态 $s_t$ | **真实 buffer 任意 $s$** |
| Rollout 长度 | 1 | 长（CEM horizon） | **短**（$1 \sim 15$） |
| Policy | 表格 $Q$ | 无（CEM） | **SAC** |
| 范式 | Background | Decision-Time | **Background** |

# Latent Space建模
## 为什么要在 latent space 建模

**state-space MBRL 的瓶颈**：

- **像素观测维度高、冗余大**，直接建 $p(I_{t+1} \mid I_t, a)$ **代价极高**
- **大部分像素与决策无关**（背景、纹理）
- rollout 越长，**像素级误差累积越严重**

> 右侧：Latent dynamics 示意图——$s_1 \to s_2 \to s_3$ 的潜状态转移，分别产生观测 $o_1, o_2, o_3$、接收动作 $a_1, a_2, a_3$、得到奖励 $r_1, r_2, r_3$。

**解决思路**：学一个紧凑的 latent 表示 $s_t$，在 latent 空间里 rollout 并规划 / 训练策略。

**两条代表路线**：**Dreamer**（重建）vs **MuZero**（value-equivalent）

### 通用框架：World Model

所有 latent MBRL 都包含**三件事**：

1. **Encoder $h$**：$o_t \to s_t$（观测压到 latent）
2. **Dynamics $d$**：$(s_t, a_t) \to (s_{t+1}, \hat{r}_t)$（latent 内涵推）
3. **Heads**：从 $s$ 预测奖励 / 值 / 策略先验 /（可选）观测重建

**差异只在两点**：

- **训练目标**：要不要**重建观测**？**Dreamer 要，MuZero 不要**
- **模型怎么用**：MCTS / MPPI-MPC / Imagination Actor-Critic

## Dreamer 系列
![[21-1-fig-1.png]]
[DREAM TO CONTROL: LEARNING BEHAVIORS BY LATENT IMAGINATION](https://arxiv.org/pdf/1912.01603)

**Hafner 等**：在 latent space 做 **imagination rollout**，用 **actor-critic** 学习策略。

- 属于 **Background Planning**：规划**只发生在训练时**；执行时**直接用 actor**
- 模型必须能**重建观测**（**ELBO / VAE 式训练**）
- 核心骨架 **RSSM**（Recurrent State-Space Model）

### RSSM：Dreamer 的骨架

**隐状态**由两部分组成，**确定性与随机性解耦**：

- **确定性** $h_t$：**GRU** 递推 $h_t = f(h_{t-1}, z_{t-1}, a_{t-1})$
- **随机** $z_t$：后验 $q(z_t \mid h_t, o_t)$ &emsp; 先验 $p(z_t \mid h_t)$

**预测头**：观测重建 $\hat{o}$、奖励 $\hat{r}$、终止 $\hat{d}$

**训练目标（ELBO）**：

$$\mathcal{L} = \underbrace{\mathbb{E}_q\big[\log p(o \mid h, z)\big]}_{\text{重建}} + \underbrace{\mathbb{E}_q\big[\log p(r \mid h, z)\big]}_{\text{奖励}} - \underbrace{\text{KL}\!\big(q(z \mid h, o)\,\|\,p(z \mid h)\big)}_{\text{后验} \to \text{先验}}$$

> **KL** 让先验逼近后验 ⇒ **推断时没有观测也能预测 $z$**

### Imagination Actor-Critic

给定真实经验推断出的 $(h_t, z_t)$，在**模型中**向前展开 $H$ 步（v1 典型 $H = 15$）：

$$a_k \sim \pi_\psi(\cdot \mid h_k, z_k)$$

$$z_{k+1} \sim p(z' \mid h_k, z_k, a_k) \quad \text{（先验，不再看真实观测）}$$

$$\hat{r}_k,\ \hat{v}_k \leftarrow \text{预测头}$$

- **Critic** 用 $\lambda$-return 回归
- **Actor 直接通过可微 latent 动力学反传梯度**（解析梯度）
- v2/v3 离散动作用 **REINFORCE + entropy 正则**

### Dreamer v1 / v2 / v3

|            | **v1 (2020)** | **v2 (2021)**         | **v3 (2023)**                                    |
| ---------- | ------------- | --------------------- | ------------------------------------------------ |
| latent $z$ | 高斯            | **类别 $32 \times 32$** | 类别 $32 \times 32$                                |
| 动作空间       | 连续            | 离散 + 连续               | 离散 + 连续                                          |
| Actor 梯度   | 解析反传          | REINFORCE + entropy   | REINFORCE + 归一化                                  |
| 值回归        | MSE           | MSE                   | <font color="#ff0000">**symlog + twohot**</font> |
| 主战场        | DMControl     | Atari **超过 Rainbow**  | <font color="#ff0000">**一套超参通吃**</font>          |

- **类别 latent** ⇒ **稀疏可枚举**，更易优化、更稳定
- **v3** 把"算法通用性"拉到新高度：**首个不需要任务级调参的通用 MBRL**

### Dreamer v3 亮点

**目标**：**一套超参数通吃所有任务**（连续 / 离散 / 稀疏 / 稠密 / 像素 / 向量）

- **symlog 预测**：$\text{symlog}(x) = \text{sign}(x) \log(1 + |x|)$，**消除奖励 / value 的尺度差异**
- **twohot 编码**：用**分类分布**回归**连续值**，比 MSE 稳定
- **KL balancing + free bits**：防止**后验塌缩 / 先验发散**
- **percentile return normalization**：稳定 **actor**

#### 成就

- **Minecraft 从零学到钻石**（首个无示教、无课程）
- **150+** 基准全部**持平或超过专用算法**

### Dreamer v4：离线世界模型内训练

Hafner 等 2025：*Training Agents Inside of Scalable World Models*

1. **Pretrain World Model**
   从 v1–v3 的 RSSM 转向 **MAE-style causal tokenizer + dynamics transformer**：
   - **tokenizer**：压缩视频帧
   - **dynamics model**：预测 **action-conditioned latent video**
2. **Finetune Agent**
   在 world model 中插入 **task tokens**，接上 **policy head** 和 **reward head**；用**离线轨迹**做 **BC**，并**学习任务奖励**
3. **Imagination RL**
   不再访问真实环境，**完全在 world model 里生成轨迹**，用 **imagined reward / value** 继续 RL 训练 policy

> **关键变化**：Dreamer 从"**在线小模型高效学习**"走向"**离线大世界模型内训练**"

#### 代表结果

- **Minecraft offline diamond challenge**：**仅用 2.5K 小时 VPT contractor 数据**
- **首个纯离线拿到钻石的 agent**：diamond 成功率 **0.7%**，iron pickaxe 约 **29%**
- **2B 参数世界模型**，$640 \times 360$，单 H100 约 **21 FPS**，**9.6s context**

## MuZero 系列：Value Equivalence

**另一条路线**：

> *"Don't model what you see, model what matters for acting."*

**Value Equivalence Principle**：只要求模型输出的 $r$、$v$、$\pi$ 与真实环境一致，**不要求能重建观测**。

- 放宽表示约束 ⇒ latent **自动学到"决策相关"的抽象**
- 避免浪费容量去拟合与决策无关的像素

**演进**：AlphaGo（完美模型）→ MuZero（学 latent 模型）→ TD-MPC / TD-MPC2（连续控制）

### AlphaGo：神经网络给 MCTS 剪枝

围棋状态空间 $\sim 10^{170}$，暴力搜索不可行；思路是**用神经网络告诉 MCTS 哪里值得看**。

- **策略网络** $P(a \mid s)$：**监督学习 3000 万步人类棋谱**，把 361 个候选点收敛到少数几个
- **价值网络** $V(s)$：**自对弈几千万盘**，直接估计当前局面胜率
- **MCTS**：$P$ **指方向**、$V$ **截断推演**，**2016 击败李世石**

> **代价**：**依赖人类棋谱**，**继承了人类的定式与偏见**。

### AlphaZero：MCTS 作为策略提升算子

**Zero human knowledge**：只知规则，从随机起步自对弈，**100:0 碾压 AlphaGo**。

- 策略 + 价值合并为单个 **ResNet 双头**：$(p, v) = f_\theta(s)$
- **MCTS** 以 $p$ 为先验展开深度搜索，**访问次数给出改进策略 $\pi$**
- 对弈真实胜负 $z$ 校准 $v$，用 $\pi$ 监督 $p$

$$\mathcal{L} = (z - v)^2 - \pi^\top \log p + c \|\theta\|^2$$

> **MCTS 是 policy improvement operator**：把算力算出的**真理蒸馏回网络直觉**。

**前提**：规则写死的**完美模拟器**；Atari / 真实世界**没有**，所以 **MuZero 要把模型一起学**。

### MuZero：学习 Value-Equivalent 模型

**三个网络全部在 latent space 工作：**

| 网络 | 作用 |
|---|---|
| **Representation $h$** | $s_0 = h(o_{1:t})$，从观测到初始 latent |
| **Dynamics $g$** | $(s_{k+1}, \hat{r}_{k+1}) = g(s_k, a_k)$ |
| **Prediction $f$** | $(\hat{p}_k, \hat{v}_k) = f(s_k)$ |

**不监督观测重建！** 只训 $r, v, \pi$ 一致：

$$\mathcal{L} = \sum_k \Big[ \ell_r(r_k, \hat{r}_k) + \ell_v(z_k, \hat{v}_k) + \ell_p(\pi_{\text{MCTS}}, \hat{p}_k) \Big]$$

**决策阶段**：**AlphaZero 风格 MCTS**（dynamics 来自学习，**可用于未知环境**）

### MuZero 的成就与扩展

- **围棋 / 象棋 / 将棋**：达到 AlphaZero 水平，**即使不给规则**
- **Atari 超越** Rainbow / R2D2 / SimPLe ——**首个同时称霸棋类和 Atari 的算法**

#### 后续扩展

- **Sampled MuZero**：连续动作空间
- **Stochastic MuZero**：随机环境
- **EfficientZero**：大幅提升样本效率

> 但 MCTS 在**高维连续动作上代价高** ⇒ **TD-MPC 换成 MPPI**

### TD-MPC：学一个控制用 latent 模型

Hansen 等 2022：把 MuZero 的 **value-equivalent model** 搬到**连续控制**，用 **MPC 规划代替 MCTS 搜索**。

**学什么**：

$$z_t = h_\theta(o_t), \quad \hat{z}_{t+1} = d_\theta(z_t, a_t)$$

$$\hat{r}_t = R_\theta(z_t, a_t), \quad \hat{Q}_t = Q_\theta(z_t, a_t)$$

- **不重建观测** $o_t$
- **reward / $Q$ / latent** 一致性一起训
- $\pi_\theta$ **辅助规划**并给 **terminal action**

[Temporal Difference Learning for Model Predictive Control](https://arxiv.org/pdf/2203.04955)

### TD-MPC：Loss 里每一项在训什么

从 replay buffer 采样真实片段，用真实动作在 latent 里 unroll：

$$\hat{z}_{k+1} = d_\theta(\hat{z}_k, a_k), \quad \hat{r}_k = R_\theta(\hat{z}_k, a_k), \quad \hat{Q}_k = Q_\theta(\hat{z}_k, a_k)$$

$Q$ 用 **TD bootstrap** 监督：

$$\mathcal{L}_{\text{model}} = \sum_k \underbrace{\|\hat{r}_k - r_k\|^2}_{\text{reward}} + \underbrace{\big\|\hat{Q}_k - \big(r_k + \gamma Q_{\theta^-}(z_{k+1}, \pi_\theta(z_{k+1}))\big)\big\|^2}_{\text{TD value}} + \underbrace{\|\hat{z}_{k+1} - h_{\theta^-}(o_{k+1})\|^2}_{\text{latent consistency}}$$

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{model}} + \underbrace{\lambda_\pi \big[\, -Q_\theta(z_k, \pi_\theta(\text{sg}(z_k)))\,\big]}_{\mathcal{L}_\pi}$$

> $\theta^-$ 是 **EMA target network**：下一帧编码只作为**慢更新的 latent target**。

### TD-MPC：用 MPPI 做短视野规划

执行时从当前观测编码出 $z_t$，在 latent dynamics 里评估候选动作序列：

$$a_{t:t+H-1} = (a_t, \ldots, a_{t+H-1})$$

$$\hat{z}_{t+k+1} = d_\theta(\hat{z}_{t+k}, a_{t+k}), \quad \hat{r}_{t+k} = R_\theta(\hat{z}_{t+k}, a_{t+k})$$

**只优化到** $a_{t+H-1}$；终点 $z_{t+H}$ 之后的价值用 **policy prior 补上**：

$$J(a_{t:t+H-1}) = \sum_{k=0}^{H-1} \gamma^k \hat{r}_{t+k} + \gamma^H\, Q_\theta\big(\hat{z}_{t+H}, \pi_\theta(\hat{z}_{t+H})\big)$$

- **Terminal $Q$** 负责**长远未来**，因此 $H$ 可以**很短**（典型 5）
- 短 horizon **降低 compounding error**；MPPI 只负责**局部动作优化**
- $\pi_\theta$ 作为 **proposal** 采样候选动作，让搜索**更快**、**更贴近高价值区域**

### TD-MPC2：MBRL 的通用基线

Hansen 等 2024：保留 TD-MPC 的核心范式，但把重点放在 **robustness + scaling + multi-task**。

- **LayerNorm + Mish**，latent 用 **SimNorm** 防止**尺度漂移 / 梯度爆炸**
- **reward 和 value** 改成 **log-space discrete regression**，降低 **reward scale 敏感性**
- 多个 Q 组成 **ensemble**，TD target 用 **conservative min**
- **task embedding + padding + action mask**，支持不同 **embodiment / action space**

**结果**：**一套超参跑 104 个任务**；**单个 317M agent 可训练 80 个任务**

## Dreamer vs MuZero：两种哲学

|  | **Dreamer** | **MuZero / TD-MPC** |
|---|---|---|
| 建模目标 | 重建 + 奖励 + 值 | **仅 $r, v, \pi$ 一致** |
| latent 约束 | **必须能解码像素** | **任意内部表示** |
| 使用模型方式 | Imagination Actor-Critic | MCTS / MPPI-MPC |
| 范式 | Background Planning | **Decision-Time Planning** |
| 典型代表 | Dreamer v3 / v4 | MuZero, TD-MPC2 |
# 全局总结

- **整体介绍**：MBRL **显式建模环境**，两种 **planning 范式**
- **MBRL 基础**：Dyna（**Background**）/ MPC、MCTS（**Decision-Time**）
- **State Space**：PETS（**决策时规划 + 集成**）/ MBPO（**短 branched rollout + SAC**）
- **Latent Space**：Dreamer（**重建式** world model）/ MuZero（**value-equivalent**）
