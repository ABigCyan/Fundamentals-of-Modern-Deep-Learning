### 流匹模型 

**目标**：将一个简单的先验分布 $p_0$（例如高斯噪声）转换为一个复杂的数据分布 $p_1$（例如图像）。

我们可以用常微分方程（ODE）来定义一个**连续归一化流（Continuous Normalizing Flow, CNF）**，而不再使用离散步骤：

#### ODE 公式

$$\frac{d}{dt} x_t = u_t(x_t), \quad x_0 \sim p_0(x)$$

- $x_t \in \mathbb{R}^d$：数据在时刻 $t \in [0, 1]$ 的状态。
- $u_t : \mathbb{R}^d \to \mathbb{R}^d$：一个**时变向量场**（速度）。
- 如果我们知道完美的 $u_t$，就只需采样噪声 $x_0$，然后模拟 ODE 到 $t = 1$，就能得到一张完美的图像！

![[17-1-fig-1.png]]

**Flow Trajectory（流轨迹）** $\psi_t(x_0)$ $\xleftarrow{\text{Solving gives}}$ **ODE**: $\dfrac{dx_t}{dt} = u_t(x_t)$ $\xleftarrow{\text{Defines}}$ **Vector Field（向量场）** $u_t(x)$

**生成式 ODE 的核心思想**：神经网络不是直接学习流本身，而是学习**向量场 $u_t(x)$**。一旦学到了，就可以通过积分来描绘轨迹。

我们如何训练一个神经网络 $v_\theta(x, t)$ 来学习这个理想的向量场 $u_t(x)$？

#### 理想流匹配（Flow Matching, FM）目标

$$\mathcal{L}_{\text{FM}}(\theta) = \int_0^1 \mathbb{E}_{x \sim p_t(x)} \left[ \left\| v_\theta(x, t) - u_t(x) \right\|^2 \right] dt$$

#### 问题

要计算这个目标，我们需要知道**边缘概率路径** $p_t(x)$ 和**目标边缘向量场** $u_t(x)$。对于复杂的数据集，$u_t(x)$ 是高度难以处理的！你没办法直接解析地写出所有自然图像的速度场。 

### 条件流匹配（Conditional Flow Matching, CFM）
 
如果不为整个数据集一次性建模，而是为**单个数据点** $x_1$ 定义一个流，会怎么样？

1. 采样一张真实图像 $x_1 \sim q(x_1)$。
2. 定义一个**条件概率路径** $p_t(x \mid x_1)$（例如，从噪声平滑地移动到恰好是 $x_1$）。
3. 该条件路径对应一个**条件向量场** $u_t(x \mid x_1)$，它是**简单且已知**的！

#### 条件流匹配（CFM）目标

$$\mathcal{L}_{\text{CFM}}(\theta) = \int_0^1 \mathbb{E}_{x_1 \sim q(x_1)} \mathbb{E}_{x \sim p_t(x \mid x_1)} \left[ \left\| v_\theta(x, t) - u_t(x \mid x_1) \right\|^2 \right] dt$$

#### 数学魔法

$\nabla_\theta \mathcal{L}_{\text{FM}} = \nabla_\theta \mathcal{L}_{\text{CFM}}$。最小化**可处理的**条件损失，恰好等价于最小化原本**不可处理**的边缘损失！

> [!note]
> **已知**: $p_t(x|x_1) = N(\mu_t(x_1), \sigma_t^2 I)$
> 
> $$x_t = \mu_t(x_1) + \sigma_t \epsilon, \quad \epsilon \sim N(0, I)$$
> 
> $$\frac{dx_t}{dt} = \dot\mu_t(x_1) + \dot\sigma_t\, \epsilon$$
> 
> 由 $x_t = \mu_t + \sigma_t \epsilon$ 得:
> 
> $$\epsilon = \frac{x_t - \mu_t(x_1)}{\sigma_t}$$
> 
> 
> $$\frac{dx_t}{dt} = \dot\mu_t(x_1) + \dot\sigma_t \cdot \frac{x_t - \mu_t(x_1)}{\sigma_t}$$
> 
> $$\boxed{u_t(x|x_1) = \dot\mu_t(x_1) + \frac{\dot\sigma_t}{\sigma_t}\big(x - \mu_t(x_1)\big)}$$
> 
> 整体分布流动太复杂 → 拆成无数条「噪声 → 具体 $x_1$」的简单条件高斯路径 → 用每条路径的可算速度场当监督 → 网络通过条件平均自动还原整体速度场。

### Diffusion & FM

- 扩散模型可以由一个随机微分方程（SDE）来描述。
- 它也有一个确定性的对应物：概率流 ODE（PF-ODE）。
- 当 $t \in [0, 1]$（数据 $\to$ 噪声）时，SDE 和 PF-ODE 享有相同的边缘分布 $p_t(x)$，而 PF-ODE 提供了一个显式的向量场视角。

如果我们把 FM 的参数设置为去匹配扩散的时间表（例如，方差保持）：

$$\mu_t(x_1) = \alpha_t\, x_1, \quad \sigma_t = \sqrt{1 - \alpha_t^2}$$

把它代入我们的流匹配公式，$v_\theta$ 学到的东西恰好等价于扩散中的噪声预测网络 $\epsilon_\theta$！

在比较之前，我们必须先澄清"时间方向"上的混乱：

**扩散模型（Diffusion）的 Convention**

- 前向过程（加噪）：Data（$t = 0$）$\xrightarrow{\text{SDE}}$ Noise（$t = 1$）。
- 生成过程（去噪）：Noise（$t = 1$）$\xrightarrow{\text{ODE}}$ Data（$t = 0$）。

**流匹配（Flow Matching）的 Convention**

- 生成过程：Noise（$t = 0$）$\xrightarrow{\text{ODE}}$ Data（$t = 1$）。

**让我们对齐它们！**

$t = 0$ 是纯噪声，$t = 1$ 是真实数据。

Diffusion 原生存在于**随机（SDE）**世界，Flow Matching 原生存在于**确定（ODE）**世界。它们怎么会等价呢？

#### Diffusion（SDE）

通过布朗运动 $W_t$ 加入噪声：

$$dx = f_t(x)\, dt + g(t)\, dW_t$$

**定理（Song et al., 2021）**：每一个 SDE 都有一个叫作**概率流 ODE（PF-ODE）的确定性孪生兄弟，它在所有时刻都共享完全相同的边缘分布** $p_t(x)$：

$$\frac{dx}{dt} = \underbrace{f_t(x) - \frac{1}{2} g(t)^2 \nabla \log p_t(x)}_{v_t(x)}$$

Flow Matching 直接参数化并学习这个确定性向量场 $v_t(x)$，目标是 PF-ODE。

#### 边缘化

$$u_t(x_t) = \mathbb{E}_{q(x_1 \mid x_t)} \left[ u_t(x_t \mid x_1) \right]$$

我们使用线性形式 $\mu_t(x_1) = \alpha_t\, x_1$。代入我们之前的条件向量场：

$$u_t(x_t) = \mathbb{E}_{q(x_1 \mid x_t)} \left[ \dot{\alpha}_t\, x_1 + \frac{\dot{\sigma}_t}{\sigma_t}(x_t - \alpha_t\, x_1) \right]$$

重新整理各项：

#### 边缘向量场（中间形式）

$$u_t(x_t) = \frac{\dot{\sigma}_t}{\sigma_t}\, x_t + \left( \dot{\alpha}_t - \frac{\dot{\sigma}_t \alpha_t}{\sigma_t} \right) \mathbb{E}_{q(x_1 \mid x_t)}[x_1]$$
从带噪点出发，向数据密度更高的方向移动。

#### Tweedie 公式

$$\nabla_{x_t} \log p_t(x_t) = \mathbb{E}_{q(x_1 \mid x_t)} \left[ -\frac{x_t - \alpha_t x_1}{\sigma_t^2} \right]$$

$$\mathbb{E}[x_0 \mid x_t] = \frac{x_t + \sigma_t^2 \nabla_{x_t} \log p_t(x_t)}{\alpha_t}$$

#### 直觉：

- $x_t$：我们当前观测到的带噪样本。
- $\nabla \log p_t(x_t)$：指向更可能数据的方向。
- $\sigma_t^2$：我们应当修正它的强度。
- $1/\alpha_t$：缩放回干净数据的坐标。

现在，我们把 $\mathbb{E}[x_1 \mid x_t]$ 代回我们的边缘向量场：

$$u_t(x_t) = \frac{\dot{\sigma}_t}{\sigma_t}\, x_t + \left( \dot{\alpha}_t - \frac{\dot{\sigma}_t \alpha_t}{\sigma_t} \right) \left[ \frac{x_t + \sigma_t^2 \nabla \log p_t(x_t)}{\alpha_t} \right]$$

将 $x_t$ 和 Score Function 的项展开并分组：

#### 一般高斯流匹配 ODE

$$u_t(x_t) = \underbrace{\frac{\dot{\alpha}_t}{\alpha_t}}_{\text{Drift (ODE)}}\, x_t + \underbrace{\left[ \frac{\dot{\alpha}_t \sigma_t^2 - \dot{\sigma}_t \alpha_t \sigma_t}{\alpha_t} \right]}_{\text{Diffusion (ODE)}} \nabla_{x_t} \log p_t(x_t)$$

在方差保持（VP）的 Diffusion 中，时间表被严格约束为保持方差为 1：

$$\alpha_t^2 + \sigma_t^2 = 1$$

对时间 $t$ 求导：

$$2\alpha_t \dot{\alpha}_t + 2\sigma_t \dot{\sigma}_t = 0 \quad \Rightarrow \quad \dot{\sigma}_t = -\frac{\alpha_t \dot{\alpha}_t}{\sigma_t}$$

让我们把这个 $\dot{\sigma}_t$ 代入刚才的 Score 系数：

$$\text{Coefficient} = \frac{\dot{\alpha}_t \sigma_t^2 - \left( -\frac{\alpha_t \dot{\alpha}_t}{\sigma_t} \right) \alpha_t \sigma_t}{\alpha_t}$$

$$\text{Coefficient} = \frac{\dot{\alpha}_t \sigma_t^2 + \dot{\alpha}_t \alpha_t^2}{\alpha_t} = \frac{\dot{\alpha}_t (\sigma_t^2 + \alpha_t^2)}{\alpha_t} = \frac{\dot{\alpha}_t}{\alpha_t}$$

把化简后的系数代回去，VP 路径下的 Flow Matching ODE 就变得**极其简单**：

#### VP Flow Matching ODE

$$u_t(x_t) = \frac{\dot{\alpha}_t}{\alpha_t}\, x_t + \frac{\dot{\alpha}_t}{\alpha_t} \nabla_{x_t} \log p_t(x_t)$$

在 Song et al. 的连续时间 VP Diffusion 中，时间表由 $\beta_t$ 定义，其中 $\dfrac{\dot{\alpha}_t}{\alpha_t} = -\dfrac{1}{2}\beta_t$。代入后得到：

#### VP Diffusion PF-ODE

$$\frac{dx_t}{dt} = -\frac{1}{2}\beta_t\, x_t - \frac{1}{2}\beta_t \nabla_{x_t} \log p_t(x_t)$$

**它们是完全相同的！**

> [!note]
> 在选择与 VP Diffusion 具有相同边缘概率路径 pt(x)p_t(x) 的高斯条件路径时，CFM 边缘化得到的 FM 向量场，恰好等于 VP-SDE 对应的 Probability Flow ODE 向量场。

### 从 Diffusion 到最优传输（OT）

![[17-1-fig-2.png|605]]

扩散轨迹是**曲线**的。曲线轨迹需要很多 ODE 求解器步数（例如 50–1000 步）才能精确模拟。

> [!note]
> 扩散模型它在每个位置、每个时间的速度方向都可能不同​，因此通常积分出来是曲线
> 

**我们能让轨迹变成一条直线吗？** 可以！最优传输（OT）路径：

$$\mu_t(x_1) = t x_1, \quad \sigma_t = 1 - t$$

$$x_t = (1 - t) x_0 + t x_1 \quad \Longrightarrow \quad u_t(x \mid x_1) = x_1 - x_0$$

速度是**常数**！这允许**极快的推理**（更少的步数）。

#### OT Flow Matching 算法（训练）

```
# v_theta(z, t): predict velocity field
# x: data batch ~ p_data
# e: noise batch ~ p0
t = rand_uniform(0, 1)               # scalar or per-sample
x = sample_data(B)
e = randn_like(x)
# --- OT pairing on mini-batch --- 
C[i,j] = || x[i] - e[j] ||^2。       #（可选）
P = sinkhorn(C)                      # soft OT coupling (B x B), stopgrad(P)
(i,j) = sample_pairs(P, B)           # or hard assignment (permutation)
# --- flow matching loss ---
z  = (1 - t) * e[j] + t * x[i]       # OT bridge (linear interpolant)
u_t = x[i] - e[j]                    # target velocity (d/dt z)

u  = v_theta(z, t)
err = u - stopgrad(u_t)
loss = mean(||err||^2)
```

> [!note]
> OT-FM 不是根据“离终点还有多远”决定速度，OT-FM 不是根据“离终点还有多远”决定速度，而是人为规定：从 x0​ 到 x1​ 做匀速直线运动。
> 这仍然是固定 x0,x1的条件速度。最终网络学到的边缘速度场$v_\theta(x,t)$ 一般仍然可能依赖 t。

#### OT 真的是一条直线吗？

**事实**：*条件* 路径是直的。但 *边缘* 路径（网络实际学到的）**不是**。

- 训练时，我们把随机噪声 $x_0$ 与随机图像 $x_1$ 配对（**独立耦合**）。
- 因为配对是随机的，路径在潜空间中**严重交叉**。
- 在交叉点处，神经网络预测**平均方向**。
- 交叉直线的平均产生**弯曲轨迹**！

#### Rectified Flow（Reflow）：拉直边缘路径

我们如何阻止路径交叉？**修正流**（Rectified Flow）通过**重新配对**（Relabeling）解决这一问题。

**步骤 1：训练基础模型（1-Rectified）**
	用独立耦合（随机 $x_0$, $x_1$）训练一个标准 OT-Flow Matching 模型。
	此时轨迹是弯曲的。

**步骤 2：重新配对 / 模拟**
	用训练好的 ODE 生成样本。保留配对关系
	如果噪声 $z_0$ 生成了图像 $z_1$，它们就是一对**自然配对**（natural pair）。

**步骤 3：回流（2-Rectified）**
	训练*新的*模型，但这次用配对 $(z_0, z_1)$ 代替随机配对。
	因为 $z_0$ 自然流向 $z_1$，**路径不再交叉**。

![[17-1-fig-3.png]]

#### 修正流的终极好处

如果边缘轨迹是**完全没有交叉的完美直线**，则向量场**关于时间恒定**（$u_t \approx \text{const}$）。

**一步生成**

我们可以用**单步 Euler** 求解 ODE：

$$ \text{Image} = \text{Noise} + u_\theta(\text{Noise}) \times \Delta t $$

### 总结：

- **Flow Matching (FM)** 是一个通过学习向量场来训练生成式 ODE 的通用框架。

- **条件 FM** 通过把路径匹配到单张图像，使训练变得易处理，数学上等价于匹配整个分布。

- **扩散模型** 仅仅是 Flow Matching 的一个子集，使用**弯曲的高斯路径**。

- **最优传输**（OT）使用**直线条件路径**来加速生成。

- **修正流**（Rectified Flow）使用模拟-重配对来修复"交叉"问题，使*整体*流变成直线，从而实现**一步生成**。
