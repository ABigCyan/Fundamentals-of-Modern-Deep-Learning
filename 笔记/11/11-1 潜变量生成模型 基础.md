我们用贝叶斯假设一个数据生成的关系：
$$p_\theta(x, z) = p(z) \, p_\theta(x \mid z).$$
其中：
<center>latent variable z 、observation x 、 parameters θ </center>

# 我们想从这个模型里得到什么？

- **生成（Generation）：** 先采样 $z \sim p(z)$，再采样 $x \sim p_\theta(x \mid z)$ ⇒ 生成新的 $x$。

- **解释 /推断（Explanation / Inference）：** 给定一个 $x$，反推它可能的"原因" $z$：$p_\theta(z \mid x)$。

- **学习（Learning）：** 选择参数 $\theta$，让模型对数据赋予较高的概率：

$$\max_{\theta} \sum_{n=1}^{N} \log p_\theta(x_n), \qquad p_\theta(x) = \int p_\theta(x, z) \, dz.$$
### **通过潜变量"原因"来表征复杂的 $p(x)$：**

$$p_\theta(x) = \int p(z)\, p_\theta(x \mid z)\, dz$$

- **多个潜变量**：令 $z = (a, b, c)$。

$$p_\theta(x, a, b, c) = p(a, b, c)\, p_\theta(x \mid a, b, c)$$

- **建模能力来源于先验中的 `结构`**（例如：条件独立性）：

$$p(a, b, c) = p(a)\, p(b \mid a)\, p(c \mid a, b) \quad \text{（总是成立的）}$$

例如，若 $c \perp (a, b)$：$$p(a, b, c) = p(a)\, p(b \mid a)\, p(c)$$
训练仍然希望通过最大似然来拟合数据：

$$\max_{\theta} \sum_{n=1}^{N} \log p_\theta(x_n).$$

证据$p_\theta(x)$ 是对所有解释 $z$ 的积分：

$$p_\theta(x) = \int p_\theta(x, z)\, dz = \int p(z)\, p_\theta(x \mid z)\, dz, \qquad \log p_\theta(x) = \log \int p(z)\, p_\theta(x \mid z)\, dz.$$

- $z$ 通常是**高维** ⇒朴素数值积分不可行。
- $p_\theta(x \mid z)$ 由**神经网络**定义 ⇒ 一般没有闭式积分。

**所以：潜变量带来了更强的表达能力，但也让边缘似然 $p_\theta(x)$难以计算（intractable）。**

求梯度时：
**从**$$p_\theta(x) = \int p_\theta(x, z)\, dz.$$
**然后**$$\nabla_\theta \log p_\theta(x) = \frac{1}{p_\theta(x)} \nabla_\theta \int p_\theta(x, z)\, dz = \frac{1}{p_\theta(x)} \int p_\theta(x, z)\, \nabla_\theta \log p_\theta(x, z)\, dz.$$
> [!note]
> 
> **log trick**
> 第一步：可以更改优化目标$\nabla_\theta p_\theta(x)$ -> $\nabla_\theta \log p_\theta(x)$
> 
> 第二步：对任何（关于 θ 可微的）正函数 $f$：$\nabla_θ f = f \cdot \nabla_θ \log f$
> 

**把里面的比值识别为后验分布：**

$$\frac{p_\theta(x, z)}{p_\theta(x)} = p_\theta(z \mid x) \quad \Longrightarrow \quad \nabla_\theta \log p_\theta(x) = \mathbb{E}_{p_\theta(z \mid x)}\big[\nabla_\theta \log p_\theta(x, z)\big].$$

-许多不同的 $z$都可以解释同一个 $x$。
- 更新 $\theta$ 时，需要对这些解释做一个**加权平均**。
- 这些权重恰好就是 $p_\theta(z \mid x)$。
- 如果 $p_\theta(z \mid x)$不可计算（因为 $p_\theta(x)$不可计算），那么训练就会变得不可行，或者噪声很大、很不稳定。

- 我们想要的是潜变量的后验分布，但它不可计算（intractable）：

$$p_\theta(z \mid x) \text{很难计算。}$$

- 所以我们把自己限制在一个可计算的分布族中：

$$\mathcal{Q} = \{q_\phi(z \mid x)\} \quad \text{（通常采用摊销 inference）}$$

### Knob 1：依赖结构（因子分解方式）
在可计算性与捕捉真实后验中相关性之间做权衡。

- **Mean-field（平均场）：**
$$q(a, b, c \mid x) = q(a \mid x)\, q(b \mid x)\, q(c \mid x)$$

- **Structured（带结构）：**
$$q(a, b, c \mid x) = q(a \mid x)\, q(b \mid a, x)\, q(c \mid x)$$

### Knob 2：每个因子的形式 / 表达能力
先从简单的开始（例如对角高斯），如果不够用再升级（例如更丰富的协方差 / normalizing flow / 混合模型）。

### Knob 3：摊销（amortization）—— 逐 $x$ 推断 vs 逐样本优化

$$q_\phi(z \mid x) \text{（测试时很快）} \quad \text{vs} \quad q_\lambda(z) \text{（对每个样本单独优化）}$$

### 训练生成模型的目标：

$$\max_{\theta} \log p_\theta(x) \;=\; \max_{\theta} \log \int p_\theta(x, z)\, dz$$

用 $q_\phi(z \mid x)$ 近似后验：易于采样并且可微分（encoder）。

 核心思路：只要我们能计算关于 $q_\phi(z \mid x)$ 的期望，就应该用这些期望构造一个**可计算的目标函数**，使它与 $\log p_\theta(x)$ 相关。

> **ELBO 正是这样一个可计算的目标。**

从 evidence 出发：

$$\log p_\theta(x) = \log \int p_\theta(x, z)\, dz = \log \int q(z)\, \frac{p_\theta(x, z)}{q(z)}\, dz = \log\, \mathbb{E}_{q(z)}\!\left[\frac{p_\theta(x, z)}{q(z)}\right]$$

> [!note]
> 期望公式
> **连续版**（z 是连续变量）：
> 
> $$\mathbb{E}_{q(z)}[f(z)] \;=\; \int q(z) \, f(z) \, dz$$
> 
> **离散版**（z 只取几个值）：
> 
> $$\mathbb{E}_{q(z)}[f(z)] \;=\; \sum_z q(z) \, f(z)$$


Jensen 不等式（$\log$ 是凹函数）：

$$\log \mathbb{E}_q[\,\cdot\,] \;\geq\; \mathbb{E}_q[\log(\cdot)]$$

定义 ELBO：

$$\mathrm{ELBO}(q, \theta) = \mathbb{E}_{q(z)}[\log p_\theta(x, z)] - \mathbb{E}_{q(z)}[\log q(z)] = \mathbb{E}_{q(z)}\!\left[\log \frac{p_\theta(x, z)}{q(z)}\right]$$

基本分解：

$$\log p_\theta(x) = \mathrm{ELBO}(q, \theta) + \mathrm{KL}\!\big(q(z)\,\|\,p_\theta(z \mid x)\big) \;\geq\; \mathrm{ELBO}(q, \theta)$$
> [!note]
> KL 散度，两个分布之间"距离"的度量。
> （具体可以看：[[11-3 高斯分布-对数密度是二次型的分布]]）
> 
> **公式**（连续版，PPT 用这个）：
> 
> $$KL(q \| p) = \int q(z) \log \frac{q(z)}{p(z)} \, dz = \mathbb{E}_{q(z)}\!\left[\log \frac{q(z)}{p(z)}\right]$$
> 
> **三个性质**：
> 
> - **≥ 0**（永远非负）
> - **q = p 时 = 0**（完全一样才为 0）
> - **不对称**：$KL(q\|p) \neq KL(p\|q)$，所以**不是真"距离"**，是有方向的差异
> 
> **含义**：用 q 去近似 p 时多出来的"信息浪费" / 描述代价。q 越像 p，KL 越小。

**最大化 ELBO 既会拟合模型（$\theta$），也会把 $q$ 推向真实后验。**

**关键恒等式：**

$$\log p_\theta(x) = \mathrm{ELBO}(q, \theta) + \mathrm{KL}\!\big(q(z)\,\|\,p_\theta(z \mid x)\big)$$

#### 1) 更新 $q$（固定 $\theta$）：$\log p_\theta(x)$ 关于 $q$ 是常数。

$$\max_{q} \mathrm{ELBO}(q, \theta) \iff \min_{q} \mathrm{KL}\!\big(q(z)\,\|\,p_\theta(z \mid x)\big)$$

$\Rightarrow$ **$q$ 被推向真实后验。**

#### 2) 更新 $\theta$（固定 $q$）：熵项不含 $\theta$。

$$\mathrm{ELBO}(q, \theta) = \underbrace{\mathbb{E}_q[\log p_\theta(x, z)]}_{\text{depends on } \theta} - \underbrace{\mathbb{E}_q[\log q(z)]}_{\text{independent of } \theta}$$

$$\max_{\theta} \mathrm{ELBO}(q, \theta) \iff \max_{\theta} \mathbb{E}_q[\log p_\theta(x, z)]$$

$\Rightarrow$ **$\theta$ 在当前 $q$ 下被拟合去解释数据。**

# EM 算法

#### E-step（固定 $\theta$，优化 $q$）：

$$q^{(t+1)} \in \arg\max_{q} \mathcal{L}(q, \theta^{(t)}) \iff \min_{q} \mathrm{KL}\!\big(q(z)\,\|\,p(z \mid x, \theta^{(t)})\big)$$

所以最好的解释就是当前的后验：

$$q^{(t+1)}(z) = p(z \mid x, \theta^{(t)})$$

> "在当前规则 $\theta^{(t)}$ 下，哪种潜变量解释最合理？"

#### M-step（固定 $q$，优化 $\theta$）：

$$\theta^{(t+1)} \in \arg\max_{\theta} \mathcal{L}(q^{(t+1)}, \theta) = \arg\max_{\theta} \mathbb{E}_{q^{(t+1)}}\big[\log p(x, z \mid \theta)\big]$$

> "把软性的潜变量解释当作权重 / soft label，然后重新拟合模型规则。"


## 贝叶斯思想：把未知量当成随机变量，用贝叶斯规则更新信念。

### 今天做的事（基于点估计 $\theta$ 的潜变量推断）：

- 使用先验 $p(z)$ 和似然 $p_\theta(x \mid z)$。
- 理想的后验是

$$p_\theta(z \mid x) = \frac{p(z)\, p_\theta(x \mid z)}{p_\theta(x)}.$$

- EM / ELBO 可以被看成：**近似或优化这个后验**，从而让学习变得可计算。

### 更一般的贝叶斯建模（参数本身也是不确定的）：

$$p(\theta \mid \mathcal{D}) \propto p(\mathcal{D} \mid \theta)\, p(\theta), \qquad p(\theta, z \mid \mathcal{D}) \propto p(\theta) \prod_{n=1}^{N} p(z_n)\, p_\theta(x_n \mid z_n).$$

- 这带来了**参数上的不确定性**（用于校准、鲁棒性、模型比较）。
- 但推断会变得更难 $\Rightarrow$ **变分贝叶斯 / MCMC / 近似方法**。

> [!note]
> 我们假设数据由潜变量 z 生成，通过最大似然最大化 $p_\theta(x)$。但是边缘似然需要积分掉 z，导致不可计算。于是我们引入一个可计算的近似后验 $q_\phi(z|x)$，让它逼近真实后验 $p_\theta(z|x)$，并通过最大化 ELBO 同时优化生成模型参数 θ 和推断模型参数 φ。
